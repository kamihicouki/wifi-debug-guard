# Store artwork

Original vector artwork for Wi-Fi Debug Guard, provided under the repository MIT license. No device identifiers or screenshots are embedded.

- icon.png: 512 × 512, opaque app icon, derived from icon.svg.
- feature.png: 1024 × 500, store feature graphic, derived from feature.svg.
- Screenshots and permission-review demonstration video must be captured from the final app with identifiers removed before submission. These graphics are not screenshots.
