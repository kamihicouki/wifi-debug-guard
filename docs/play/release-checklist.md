# Google Play提出チェックリスト

公開準備用。チェックは実測・実画面・最終成果物で確認後に更新します。2026-11-15現在、審査提出も公開も未完了です。

## アカウントと本人の操作

- [ ] 提出できる有効な開発者アカウントを確認する。閉鎖されたアカウントがあっても、別アカウントの登録状態は推定しない。
- [ ] アカウントの本人確認・連絡先確認・必要な事業者情報を所有者が完了する。個人情報を公開リポジトリに置かない。
- [ ] 新規課金、開発者契約、Play App Signing等の法的同意が必要なら所有者本人が実施する。自動代行しない。
- [ ] 公開するサポートメールを所有者が指定する。GitHubアカウントやGoogleログインメールを自動流用しない。
- [ ] 対象国、年齢層、無料設定、公開者名、広告なし等をConsoleで確認する。子供向けとして無根拠に分類しない。
- [ ] 新規個人アカウントのテスト要件が適用されるか確認する。2023-11-13より後に作成した個人アカウントでは、少なくとも12人が連続14日opt-inするclosed testが製品版アクセス申請前に必要。既存・組織アカウントへ無条件に適用しない。[公式テスト要件](https://support.google.com/googleplay/android-developer/answer/14151465?hl=en)

## 提出と公開確認

- [ ] signed AABを対象アプリへアップロードし、署名・API・権限・互換性の自動検査結果を確認する。
- [ ] 内部テスト／適用されるclosed testで実配信版を検証する。
- [ ] 審査提出ボタン後に「審査中」の実画面を確認する。草稿保存・アップロード成功を提出と同一視しない。
- [ ] 審査結果・公開状態を確認し、実際のPlayストアURLと配信版の版番号を照合する。
- [ ] C2更新・公開IDでの新規導入について、対象端末ごとの受入・再起動とMac接続の結果を確認する。これはPlay公開完了とは別の検証として記録する。
