# Google Play公開準備

このフォルダーは掲載文・申告案と根拠です。Google Playでの公開、審査提出、権限承認、アカウント確認の完了を示すものではありません。実装と最終AABを確認してから入力します。

- [掲載文案](listing.json): 日本語・英語のタイトル、短い説明、詳しい説明。文字数上限を検査済み。
- [プライバシーポリシー](privacy-policy.md): GitHubの公開ページを利用し、アプリ内から開けます。
- [申告案と審査用デモ](declarations.md): Data safety、位置情報、ADB再現手順。
- [公開チェックリスト](release-checklist.md): 完了していない項目を区別。

サポートURLは公開GitHub Issuesです。Playに公開するサポートメールアドレスは未設定です。Googleアカウントのメールアドレスを流用していません。

- [アップロード署名](upload-signing.md): 秘密鍵をGitに追加せず、ローカルで署名AABを作成する手順。
